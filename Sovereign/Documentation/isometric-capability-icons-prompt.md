# Capability icons

Create these four icons, and only these four. They are a matched set for the same screen.

1. Chat
2. Voice
3. Images
4. Video

Attach your Airbnb isometric reference images, then paste the prompt below.

---

Use the attached images as the only style reference. Match their material, camera angle, lighting, color, and finish. Do not invent a different 3D look.

Make four separate icons, one object each:

1. Chat. A physical object for talking and writing. Not a comic speech bubble, not the Messages app icon, not two flat rectangles.
2. Voice. A physical object for speaking and listening, such as a microphone. Not a row of audio bars, not a waveform, not a podcast logo.
3. Images. A physical object for making a photograph, such as a camera or a printed photo with real thickness. Not a flat landscape thumbnail, not a generic picture frame with a sun.
4. Video. A physical object for making a film, such as a small cinema camera or a film reel. Not a play button. Not a rounded rectangle with a triangle. It must not look like YouTube or any video-app logo.

Rules for the whole set:

- 3D isometric, the same camera on every icon
- One sculpted object, centered, with generous empty space around it
- Soft matte material, rounded forms, studio light from the upper left, one soft contact shadow
- Same canvas, same scale, same shadow direction
- Square, 1024 by 1024, transparent background, PNG
- No text, letters, numbers, logos, or brand marks
- No flat icons, no outlines, no emoji, no glossy plastic, no busy scenes

Name the files chat.png, voice.png, images.png, and video.png.
