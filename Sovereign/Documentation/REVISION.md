# Review revision — 24 October 2026

Armando's review supersedes the original PRD's marketing copy and default-mode behavior. This revision replaces the sparkle identity and decorative capability illustrations with restrained typography. Welcome leads with ownership, privacy, no accounts and control. Capability cards use titles, descriptions and storage totals. Actual physical memory and filesystem free space are read from macOS; model compatibility and ETA still use deterministic preview fixtures, not benchmarks.

The same supplied onboarding world is retained. Welcome is darkened for readable white type; Evil Mode uses a deep charcoal/red treatment and concise unrestricted-text/image/video concept copy. Preparation uses direct labels with remaining-time estimates. Connectors replace Connections in every visible navigation label, and provider marks replace monograms.

Evil Mode is now a switch in the composer. It changes only that conversation. New chats start Safe; onboarding can set the initial chat's mode. Appearance remains independent. A red header edge, contextual label, warmer conversation surface and red composer border distinguish Evil from Safe in both Light and Dark. The sidebar and Settings do not acquire a global Evil state.

Media cards display edge-to-edge image/video posters with consistent clipped corners and a compact footer. Preview fits the whole image with no actual-size toggle. Video uses its 16:9 frame instead of a mismatched fixed-height player. Card Edit now opens editing directly. The real bundled playback and artifact version records remain intact.

Extensions now contains Connectors, Tools and Skills. Web search and attachment reading can be enabled/disabled. Skills support create, edit, enable, disable, Markdown/text import, confirmed delete, persistence and composer access. Enabled skill names are captured with each response job. The simulator demonstrates concise/bullet styles; arbitrary instruction execution awaits real model integration. No MCP server, inference runtime, credentials or downloaded code are introduced.

New checks cover per-chat mode isolation, appearance independence, actual hardware values, skill CRUD/import/style/persistence, attachment-tool disabling and logo decoding. Existing chat, onboarding, preparation, cancellation, media versioning and real playback checks continue to pass.
